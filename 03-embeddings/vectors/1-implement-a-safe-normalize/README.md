# Implement a safe normalize

`embeddings.vectors.1` · Easy · code

Implement `normalize(v)` that returns a numpy float array of unit length pointing in the same direction as `v` (accepts lists or arrays). A zero vector has no direction: return a zero vector of the same length instead of NaNs. Do not modify the input.

Example: `normalize([3, 4])` gives `[0.6, 0.8]`; `normalize([0, 0])` gives `[0., 0.]`.
