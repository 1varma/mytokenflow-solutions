# Find the longest common prefix of prompts

`python-basics.strings.8` · Medium · code

Prompt caching rewards prompts that share a long identical beginning. Implement `common_prefix(prompts)` that returns the longest string that every prompt in the list starts with. An empty list returns `""`.

Example: `common_prefix(["You are a tutor. Q1", "You are a tutor. Q2", "You are a coach."])` returns `"You are a "`.
