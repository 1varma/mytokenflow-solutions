# Title-case model names

`python-basics.strings.5` · Easy · code

Implement `display_name(slug)` that turns a slug like `"gpt-4o-mini"` or `"llama_3_70b"` into a display name: split on `-` and `_`, capitalise the first letter of each part (leave the rest of each part as is), and join with single spaces. Empty parts (from doubled separators) are dropped.

Example: `display_name("llama_3_70b")` returns `"Llama 3 70b"`.
