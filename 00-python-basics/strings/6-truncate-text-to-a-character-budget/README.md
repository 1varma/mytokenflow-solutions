# Truncate text to a character budget

`python-basics.strings.6` · Easy · code

Implement `truncate(text, limit)` that returns `text` unchanged if it has at most `limit` characters. Otherwise return the first `limit - 3` characters followed by `"..."`, so the result is exactly `limit` characters long. You may assume `limit >= 3`.

Example: `truncate("Retrieval-augmented generation", 12)` returns `"Retrieval..."`.
