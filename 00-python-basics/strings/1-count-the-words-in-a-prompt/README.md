# Count the words in a prompt

`python-basics.strings.1` · Easy · code

Before sending text to a model you often want a rough size. Implement `word_count(text)` that returns how many words `text` has. A word is any run of non-space characters, so several spaces, tabs or newlines in a row still separate just two words. An empty or all-space string has `0` words.

Example: `word_count("  Explain   RAG\n in one line ")` returns `5`.
