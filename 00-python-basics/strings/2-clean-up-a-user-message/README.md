# Clean up a user message

`python-basics.strings.2` · Easy · code

User input arrives messy. Implement `clean_message(text)` that returns the text with leading and trailing whitespace removed and every run of internal whitespace (spaces, tabs, newlines) replaced by a single space.

Example: `clean_message("  Hello \t\n  world  ")` returns `"Hello world"`.
