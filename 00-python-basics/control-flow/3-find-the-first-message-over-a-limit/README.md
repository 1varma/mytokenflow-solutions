# Find the first message over a limit

`python-basics.control-flow.3` · Easy · code

Implement `first_over(lengths, limit)` that returns the index of the first value in `lengths` that is greater than `limit`, or `-1` if none is.

Example: `first_over([10, 80, 200, 300], 100)` returns `2`.
